# Spec Delta

## Purpose

在宿主单页应用与活动内容之间建立一条零凭证、可白名单控制的通讯通道，使活动页能提交信息与读取自身数据，却不持有任何可用于鉴权的凭据，也无法碰触宿主页面。

## ADDED Requirements

### Requirement: 活动内容的沙箱承载
活动内容 MUST 承载于 iframe 中，且该 iframe MUST 启用沙箱限制。沙箱 MUST NOT 包含允许同源访问的令牌。宿主 MUST NOT 读取或修改 iframe 内部文档，MUST NOT 向其注入脚本。

#### Scenario: 活动页无法访问宿主存储
- **WHEN** 活动内容尝试读取宿主页面的本地存储或与其通信对象
- **THEN** 访问被浏览器阻止

#### Scenario: 活动页无法接触宿主文档
- **WHEN** 活动内容尝试访问父页面的文档对象
- **THEN** 访问被浏览器阻止

#### Scenario: 宿主不注入脚本
- **WHEN** 宿主承载一个未引用桥接脚本的活动页
- **THEN** 宿主不对该文档做任何内容修改，并按下述诊断要求提示缺失

### Requirement: 消息信封与握手
两侧消息 MUST 使用统一信封，包含协议版本、消息类型，以及可选的消息标识与载荷。活动页首次就绪后 MUST 发出就绪消息，宿主收到后 MUST 下发初始化消息。握手 MUST 可重复执行且结果一致。协议版本不匹配时宿主 MUST 明确报错而非静默继续。

#### Scenario: 活动页就绪后收到初始化
- **WHEN** 活动页发出就绪消息
- **THEN** 宿主下发包含活动标识、身份描述符、接口基地址与主题令牌的初始化消息

#### Scenario: 未引入桥接脚本的活动页被诊断
- **WHEN** iframe 加载完成后在配置的等待时间内未发出就绪消息
- **THEN** 宿主展示明确的缺失提示，而非保持空白或固定高度

#### Scenario: 握手幂等
- **WHEN** 活动页重复发出就绪消息，或 iframe 被重新加载
- **THEN** 宿主重复下发初始化消息，且不产生重复的副作用

#### Scenario: 版本不匹配时明确失败
- **WHEN** 活动页声明的协议主版本与宿主实现不一致
- **THEN** 宿主展示明确的版本不匹配提示，且不下发凭据类以外的错误数据

### Requirement: 消息来源校验
宿主 MUST 通过比对消息来源窗口与自身持有的 iframe 窗口引用是否同一来校验发送方，MUST NOT 仅依赖消息中声明的来源字符串。桥接脚本 MUST 校验收到消息的来源为宿主页面来源。

#### Scenario: 其他窗口的消息被忽略
- **WHEN** 非该 iframe 的窗口向宿主发送符合信封格式的消息
- **THEN** 宿主忽略该消息，不执行任何操作

#### Scenario: 未知消息类型被忽略
- **WHEN** 收到信封合法但类型不在约定内的消息
- **THEN** 宿主忽略该消息且不报错中断

### Requirement: 身份描述符零凭证
宿主向下发送的身份描述符 MUST NOT 包含任何可用于鉴权的凭据，包括会话标识、会话令牌或等价物。描述符 SHALL 包含登录状态、用户标识、显示名、角色、匿名标识，以及该活动是否需要登录。

#### Scenario: 初始化载荷不含凭据
- **WHEN** 检查宿主下发的初始化消息
- **THEN** 其中不包含会话令牌或任何可直接用于调用后端接口的值

#### Scenario: 未登录时的描述符
- **WHEN** 当前无人登录
- **THEN** 描述符的登录状态为 false 且用户字段为空，但仍包含匿名标识与活动标识

#### Scenario: 登录状态变化时下发更新
- **WHEN** 用户在宿主内登录或登出
- **THEN** 宿主向活动页下发更新后的身份描述符

### Requirement: 操作白名单代理
活动页的全部后端交互 MUST 经宿主代理完成。宿主 MUST 仅接受预定义的操作名，MUST NOT 接受由活动页提供的任意地址、路径或接口名进行转发。请求所用的活动标识 MUST 由宿主自身路由决定，MUST NOT 采信活动页提供的值。白名单外或参数非法的请求 MUST 被拒绝。

#### Scenario: 白名单内操作被代理
- **WHEN** 活动页请求提交操作并携带内容
- **THEN** 宿主以自身会话代为调用后端提交接口并回传结果

#### Scenario: 未知操作被拒绝
- **WHEN** 活动页请求一个不在白名单内的操作名
- **THEN** 宿主返回不支持的操作用错误，且不发出任何网络请求

#### Scenario: 无法借宿主访问其他活动的数据
- **WHEN** 活动页在参数中提供另一个活动的标识
- **THEN** 宿主忽略该值并使用自身路由的活动标识

#### Scenario: 无法借宿主访问管理接口
- **WHEN** 活动页请求的操作名不在白名单内
- **THEN** 宿主不转发，管理类接口无法经由桥接触达

### Requirement: 提交前登录短路
当活动要求登录而当前未登录时，宿主 MUST 在发出网络请求之前返回结构化的登录要求错误，MUST NOT 让请求到达后端。活动页 MUST 能据此区分该情形并引导登录。

#### Scenario: 未登录时短路
- **WHEN** 活动要求登录、当前无人登录，活动页请求提交
- **THEN** 宿主返回登录要求错误，且未产生任何后端请求

#### Scenario: 已登录时正常提交
- **WHEN** 活动要求登录且用户已登录
- **THEN** 请求被正常代理到后端

### Requirement: 请求关联、超时与清理
每次代理请求 MUST 具有唯一标识并在响应中原样回传。宿主 MUST 对超时的请求返回结构化错误。iframe 被重新加载或卸载时，宿主 MUST 拒绝所有未完成的请求并释放其关联状态。

#### Scenario: 请求标识原样回传
- **WHEN** 活动页发出带标识的请求并收到响应
- **THEN** 响应中的标识与请求一致

#### Scenario: 超时返回错误
- **WHEN** 某请求在配置时间内未收到后端响应
- **THEN** 宿主返回超时错误，活动页的等待被拒绝而非永久挂起

#### Scenario: iframe 重载后未决请求被拒绝
- **WHEN** iframe 在请求未完成时被重新加载
- **THEN** 该请求被拒绝，且宿主的关联状态被清理

#### Scenario: 活动页可取消请求
- **WHEN** 活动页主动取消一个进行中的请求
- **THEN** 宿主中止该请求并使对应等待以取消错误结束

### Requirement: 上传进度与草稿代存
宿主 SHALL 在文件上传过程中向活动页回推进度。宿主 SHALL 以自身存储在活动页维度保存草稿，使活动页在不具备本地存储能力的前提下仍能跨重载保留未提交内容。草稿 MUST NOT 被持久化到后端。

#### Scenario: 上传进度被回推
- **WHEN** 活动页提交一个较大的文件
- **THEN** 宿主在上传过程中回推进度事件，最终回推完成结果

#### Scenario: 草稿跨重载保留
- **WHEN** 活动页保存草稿后 iframe 被重新加载，随后读取草稿
- **THEN** 取回先前保存的内容

#### Scenario: 草稿不落后端
- **WHEN** 活动页保存草稿
- **THEN** 不产生任何后端请求或数据库记录

#### Scenario: 草稿按活动隔离
- **WHEN** 两个不同活动页各自保存草稿
- **THEN** 彼此的草稿互不可见

### Requirement: 后端错误的可区分映射
宿主 MUST 将后端返回的错误映射为活动页可区分的结构化错误码，至少区分：需要登录、活动已关闭、名额已满、限流、校验失败。活动页 MUST NOT 需要解析 HTTP 状态码。

#### Scenario: 名额已满被区分为独立错误
- **WHEN** 后端返回名额已满
- **THEN** 活动页收到的错误码表明名额已满，与其活动已关闭、限流可区分

#### Scenario: 校验失败携带字段信息
- **WHEN** 后端返回校验失败
- **THEN** 错误中携带可定位到具体字段的信息
