# Spec Delta

## Purpose

定义单页应用的导航结构、管理台外壳与活动页宿主，并把既有视觉语言固化为可复用的设计令牌，使管理台与各活动页在观感上保持一致。

## ADDED Requirements

### Requirement: 路由结构与保留前缀
单页应用 MUST 保留 `admin`、`login`、`register`、`reset`、`api`、`content`、`data`、`assets`、`sdk` 作为内部前缀。根路径 `/` MUST 作为平台首页（见下一条），除此以外的非保留顶层路径 MUST 被解释为活动标识并导航到活动页。无法匹配到已发布活动的标识 MUST 显示未找到页面。服务端 MUST 对未知路径回退到应用入口以支持前端路由。

#### Scenario: 进入管理台
- **WHEN** 访问 `/admin` 路径
- **THEN** 进入管理台界面而非活动页

#### Scenario: 根路径是首页
- **WHEN** 访问 `/`
- **THEN** 显示平台首页，而不是重定向到管理台

#### Scenario: 顶层路径解释为活动
- **WHEN** 访问一个已发布活动的标识
- **THEN** 进入该活动的活动页

#### Scenario: 未知活动显示未找到
- **WHEN** 访问一个不存在或未发布的活动标识
- **THEN** 显示未找到页面

#### Scenario: 保留前缀不会被当作活动
- **WHEN** 访问 `/login` 或 `/assets/...`
- **THEN** 不会尝试将其作为活动标识解析

#### Scenario: 直接访问深层路径可正常加载
- **WHEN** 直接在浏览器中打开一个管理台深层路径
- **THEN** 服务端返回应用入口，前端路由正确还原该页面

### Requirement: 平台首页
根路径 SHALL 提供平台首页，作为公开入口：列出**公开的**已发布活动并提供进入其中任一活动的入口。

首页 MUST 无需登录即可访问。它 MUST NOT 列出 `private` 活动（见 event-catalog 的"活动可见性"）。活动列表加载失败时 MUST 给出提示而不是空白页。

首页 SHALL 提供按活动标识直达的输入，且该输入的候选项 MUST 只来自公开活动 —— 补全的作用是"目录里有哪些"，它既不应当、也无法代为记住一条不公开的链接。

#### Scenario: 匿名可访问首页
- **WHEN** 未登录用户访问根路径
- **THEN** 显示首页，且列出当前公开的已发布活动

#### Scenario: 首页不列出私有活动
- **WHEN** 某活动为 live 且 private
- **THEN** 它不出现在首页的列表与补全候选项中

#### Scenario: 从首页进入活动
- **WHEN** 访客点击列表中的某个活动
- **THEN** 进入该活动的活动页

#### Scenario: 没有活动时不显示空白
- **WHEN** 当前没有任何公开的已发布活动
- **THEN** 首页给出说明文字，而不是一片空白

#### Scenario: 列表加载失败时有提示
- **WHEN** 公开活动列表接口返回错误
- **THEN** 首页显示错误提示，其余版面（标题、立绘、管理台入口）仍然可用

### Requirement: 管理台外壳与访问控制
管理台 SHALL 提供活动、提交与用户三个入口的导航。未登录用户访问管理台 MUST 被引导至登录页，并在登录后回到原目标页面。非管理员用户 MUST 无法访问管理员专属页面。

#### Scenario: 未登录被引导登录
- **WHEN** 未登录用户访问管理台路径
- **THEN** 被导航到登录页，并在登录成功后回到原先请求的页面

#### Scenario: 普通用户看不到管理员入口
- **WHEN** 普通用户登录后进入管理台
- **THEN** 用户管理入口不可见且直接访问被拒绝

#### Scenario: 会话失效时回到未登录态
- **WHEN** 管理台任意请求收到 401
- **THEN** 前端清除登录状态并引导至登录页

### Requirement: 活动页宿主与加载诊断
活动页 SHALL 以沙箱 iframe 承载活动内容，源地址 MUST 由活动标识与内容版本号构造。宿主 MUST 在约定等待时间内检测活动页是否已接入桥接脚本，未接入时 MUST 显示明确的缺失提示而非空白区域。

#### Scenario: 正常承载活动内容
- **WHEN** 访问一个已发布且内容存在的活动
- **THEN** 以沙箱 iframe 加载该活动的内容入口页

#### Scenario: 内容缺失时给出提示
- **WHEN** 活动存在但内容目录中缺少入口页
- **THEN** 显示内容缺失提示而非空白 iframe

#### Scenario: 未接入桥接脚本时给出提示
- **WHEN** 活动页在等待时间内未发出就绪消息
- **THEN** 显示缺少桥接脚本的提示，指明所需的引入方式

#### Scenario: 内容版本变化时重新加载
- **WHEN** 活动的 `content_version` 递增后再次访问该活动
- **THEN** 以新的版本参数加载内容入口页

### Requirement: 设计令牌
前端 MUST 以统一的自定义属性定义颜色，且所有界面 MUST 使用这些令牌而非散落的字面量。令牌取值 MUST 为：页面底色 `#0b0b0d`、面板 `#101014`、主文字 `#cfcac4`、次级文字 `#8b8e97`、占位与禁用 `#5f626b`、主强调 `#d0202f`、亮强调 `#ff4a55`、分隔线 `rgba(255,255,255,0.09)`。界面 MUST NOT 使用渐变填充。圆角 MUST 限制为两档：按钮 7px，输入框与卡片 10px。

#### Scenario: 令牌集中定义
- **WHEN** 检视样式令牌文件
- **THEN** 上述全部颜色均以自定义属性形式定义

#### Scenario: 不使用渐变
- **WHEN** 检视界面样式
- **THEN** 不出现渐变填充

#### Scenario: 主操作使用主强调色
- **WHEN** 渲染主要操作按钮
- **THEN** 其背景取自主强调色令牌，悬停时取自亮强调色令牌

#### Scenario: 活动页与应用共享同一套令牌
- **WHEN** 宿主向活动页下发主题令牌
- **THEN** 活动页可读取到与宿主一致的颜色取值

### Requirement: 字体与焦点可见性
标题、标签与数字 MUST 使用等宽字体栈，正文 MUST 使用无衬线字体栈。键盘焦点 MUST 具备可见的焦点指示，样式为亮强调色的 2px 实线轮廓并带 3px 偏移。

#### Scenario: 数字与标签使用等宽字体
- **WHEN** 渲染表格中的数字、时间或标识
- **THEN** 其字体取自等宽字体栈

#### Scenario: 键盘聚焦可见
- **WHEN** 使用键盘在控件间移动焦点
- **THEN** 当前控件显示亮强调色轮廓

#### Scenario: 正文使用无衬线字体
- **WHEN** 渲染说明性正文
- **THEN** 其字体取自无衬线字体栈

### Requirement: 动效克制与可及性
界面过渡 MUST 为短时长的颜色与边框变化，MUST NOT 使用超过 200 毫秒的过渡。所有动效 MUST 尊重用户减少动效的系统偏好。

#### Scenario: 过渡时长受限
- **WHEN** 检视交互元素的过渡定义
- **THEN** 过渡时长不超过 200 毫秒

#### Scenario: 尊重减少动效偏好
- **WHEN** 用户的系统设置为减少动效
- **THEN** 循环或装饰性动画被停用

#### Scenario: 未找到页面保持一致观感
- **WHEN** 渲染未找到页面
- **THEN** 其配色与字体符合本节令牌与字体要求
