# Spec Delta

## Purpose

让管理员查看、筛选、审核与清理各活动收到的提交，使活动结束后信息能够被复核、导出与整理，并让误收或恶意内容可以被移除且释放配额。

## ADDED Requirements

### Requirement: 提交列表与筛选
管理员 SHALL 能够按活动分页查看提交，并可按分类标签、审核状态、提交者与时间范围筛选。列表 MUST 显示提交者标识、是否来自登录用户、提交时间与文件数量。

#### Scenario: 按活动查看提交
- **WHEN** admin 请求某活动的提交列表
- **THEN** 返回该活动的提交，分页可翻页

#### Scenario: 按分类标签筛选
- **WHEN** admin 以某分类标签筛选
- **THEN** 结果只包含该标签的提交

#### Scenario: 按审核状态筛选
- **WHEN** admin 以已接受状态筛选
- **THEN** 结果只包含该状态的提交

#### Scenario: 区分登录与匿名提交
- **WHEN** 检视提交列表
- **THEN** 能看出每条提交来自登录用户还是匿名访客

### Requirement: 审核状态流转
每条提交 SHALL 具有审核状态，取值范围为已接收、审核中、已接受、已拒绝。管理员 SHALL 能够变更状态。状态变更 MUST 被记录时间与操作者。

#### Scenario: 标记为已接受
- **WHEN** admin 将某提交标记为已接受
- **THEN** 该提交状态变为已接受，并记录操作者与时间

#### Scenario: 标记为已拒绝
- **WHEN** admin 将某提交标记为已拒绝
- **THEN** 该提交状态变为已拒绝，且该提交仍存在于列表中

#### Scenario: 非法状态被拒绝
- **WHEN** admin 提交一个不在取值范围内的状态
- **THEN** 请求被拒绝

#### Scenario: 新提交的初始状态
- **WHEN** 活动页提交信息成功
- **THEN** 该提交的初始状态为已接收

### Requirement: 删除提交释放配额
管理员 SHALL 能够删除提交。删除 MUST 在同一事务内递减该活动的已用配额，使被删除的名额立即重新可用。删除 MUST 同时移除该提交关联的文件记录与文件内容。删除失败时 MUST NOT 发生部分递减。

#### Scenario: 删除后名额释放
- **WHEN** 某活动已满额，admin 删除其中一条提交
- **THEN** 该活动的剩余名额增加 1，且新提交可被受理

#### Scenario: 删除同时移除附件
- **WHEN** admin 删除一条带附件的提交
- **THEN** 其附件记录与文件内容一并被移除，且此后无法下载

#### Scenario: 删除失败不释放名额
- **WHEN** 删除提交的过程中发生错误并回滚
- **THEN** 配额计数保持原值，且提交仍然存在

#### Scenario: 批量删除后计数正确
- **WHEN** admin 一次删除多条提交
- **THEN** 配额计数与剩余提交条数一致

### Requirement: 管理端附件访问
管理员 SHALL 能够下载任意提交中的任意附件，不受提交者限制。附件列表 MUST 展示原始文件名、类型、体积与上传时间。

#### Scenario: 下载他人提交的附件
- **WHEN** admin 下载某匿名提交中的附件
- **THEN** 得到该附件的字节内容

#### Scenario: 附件元信息可见
- **WHEN** admin 查看某条提交
- **THEN** 能看到每个附件的原始文件名、类型、体积与上传时间

#### Scenario: 附件已缺失时的处理
- **WHEN** 记录存在但文件内容已缺失
- **THEN** 响应为 404 且不暴露服务器文件系统路径

### Requirement: 提交内容按原始形态展示
管理端 MUST 以原始键值形态展示提交内容，MUST NOT 假设字段语义、MUST NOT 因字段缺失或类型不符而拒绝渲染。

#### Scenario: 任意键值可读
- **WHEN** 某提交的内容包含平台事先不知道的键
- **THEN** 管理端仍完整展示该键值

#### Scenario: 嵌套结构可见
- **WHEN** 提交内容包含嵌套对象或数组
- **THEN** 管理端以可读形式展示其结构

#### Scenario: 空内容提交可读
- **WHEN** 某提交只有附件而没有字段内容
- **THEN** 管理端正常展示该提交及其附件
