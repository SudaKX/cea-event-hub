# Spec Delta

## MODIFIED Requirements

### Requirement: 登录与会话建立
登录成功时平台 SHALL 建立服务端会话，并以仅可由服务端读取的 Cookie 下发会话凭据。会话凭据 MUST NOT 出现在响应体、页面可读存储或任何脚本可访问的位置。Cookie MUST 设置同站限制与安全属性。

平台 MUST 让**任何已登录用户**都能在界面上结束自己的会话，MUST NOT 只在管理员界面上提供该入口 —— 登出是账号持有者的基本能力，与角色无关；缺少它意味着非管理员用户除了清除浏览器数据之外没有别的办法退出。

#### Scenario: 登录成功下发不可被脚本读取的凭据
- **WHEN** 用户成功登录
- **THEN** 响应下发会话 Cookie，且该 Cookie 标记为禁止脚本读取并带同站限制

#### Scenario: 响应体不含会话凭据
- **WHEN** 检视登录成功响应
- **THEN** 响应体中不含会话凭据本身

#### Scenario: 登出使会话失效
- **WHEN** 已登录用户请求登出
- **THEN** 该会话在服务端失效，且浏览器中的凭据被清除

#### Scenario: 非管理员也能从界面登出
- **WHEN** 一个非管理员用户已登录
- **THEN** 界面上存在可用的登出入口，使用后回到未登录态

#### Scenario: 服务端不保存可用的凭据明文
- **WHEN** 检视会话记录
- **THEN** 存储的是凭据的摘要而非凭据本身
